# 運行記録アプリ（スマホの音声入力 → Googleスプレッドシート）

車の出発・到着・終了を、スマホに話しかけて記録する。Android の Chrome で使う。

- 「六甲アイランドへ出発します。私用です。買い物です。今のキロ数は2145です」
  → 日付・時刻・出発地・行き先・区分・目的・メーター 102,145 km を記録
- 「到着しました。2152キロ」→ 到着時刻と区間 7 km
- 「出発します。2152キロ」→ 停車地から再出発（何か所でも続けられる）
- 「終了。今のキロ数は2160です」→ 今回の走行 15 km を計算し、スプレッドシートの「運行」に1行足す

言った数字が 100,000 より小さいときは 100,000 を足す（設定で変えられる）。
聞き取れなかったとき・数字がおかしいとき（前回より小さい、1,000km 以上増えた）は確認画面が出る。
記録した直後の10秒間は「取り消す」が押せる。電波がないときはスマホに貯めて、つながったら送る。

## 記録を直す
「最近の記録」か、月の「運行の一覧」→ 詳細 の記録を押すと、日付・時刻・出発地・場所・区分・目的・メーターを直せる。
区分と目的は運行全体が同じものに変わる。区間km・合計km・「運行」の行は、アプリとスプレッドシートの両方で計算し直す。
古い運行は、詳細を開いたときにスプレッドシートから記録を読む。

## 月ごとの集計
画面の ‹ › で月を切り替え、業務・私用の km、業務の割合、運行の回数、目的ごとの km、運行の一覧を出す。
スプレッドシートにも「月別集計」シート（月×区分の合計、式で自動）ができる。

## ファイル
- `index.html` 画面と読み取りの処理（`manifest.json`・`sw.js`・`icon.svg` はホーム画面に置くため）
- `gas/Code.gs` スプレッドシート側の受付

## 設定（最初の1回だけ・徳永さんが行う）
1. info@second-penguin.com で新しいスプレッドシートを作る。名前は `運行記録`
   （置き場所：`PS_総務部\総務部\会計課\` を推奨）
2. 「拡張機能」→「Apps Script」を開き、最初の文字を消して `gas/Code.gs` の中身を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**　／　アクセスできるユーザー：**全員**
4. 「デプロイ」→ Googleの許可画面で許可 → 表示された `https://script.google.com/macros/s/.../exec` を Claude に渡す
5. Claude が「アプリのURL#url=（受付URL）」の形のリンクを作る。スマホの Chrome でそれを一度開くと受付URLが保存される
   （受付URLはページ本体には書かない。アプリの「設定」に直接貼ってもよい）
6. Chrome のメニュー →「ホーム画面に追加」。初回にマイクの許可を求められたら「許可」

`Code.gs` を直したときは「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」（URLは変わらない）。

## スプレッドシートの列
- 記録：記録ID／運行ID／日付／時刻／種類（出発・到着・終了）／出発地／行き先・場所／区分／目的／メーター(km)／区間km／運行の累計km／発言
- 運行：運行ID／日付／出発時刻／終了時刻／出発地／行き先（経由）／区分／目的／開始メーター／終了メーター／走行km

- 月別集計：月ごとに 業務・私用 の走行km（車両費の按分の目安）
日付・時刻の列は文字の形式にしてある（自動で日付型になって時刻がずれるのを防ぐため）。

## 注意
- 受付URLを知っている人は記録を読み書きできる。URLは人に渡さない。
- 運転中は操作しない。出発前・到着後の停車中に話す。
